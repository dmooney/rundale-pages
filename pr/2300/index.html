Swift checks on Linux

PR #2300, part of #2287. This moves CI checks; nothing in the app looks or behaves differently, so there is nothing to record on screen.

The one app source change

LimerickEndpointKit did not compile on Linux: swift-corelibs-foundation does not bridge NSNumber to CFNumber. On Apple platforms the code is the same CFNumberIsFloatType(value) call as before, inside #if canImport(Darwin); only Linux takes the new branch, which reads the number's type encoding. The iOS app's behaviour is unchanged. The Mac full gate (nightly, testflight-update) still runs the package suites against Apple's Foundation, and this PR's hosted smoke gate builds the app with the change.
