Step-by-step slash command completion

Issue 2146. iPhone 17 Pro simulator (not a physical iPhone), running the shared engine with no Endpoint configured (RundaleCommandsUITests.testCompletionOffersEachNextWordAndRunsDebugMemory, recorded with demo holds).

  1. Typing / lists every command the phone runs, including /wait, /pause, and /debug. Swiping the strip left reaches the commands past the screen edge (/resume, /debug, /flags); swiping right returns. Typing de narrows to /debug.
  2. Tapping /debug inserts it with a space; the strip offers the debug views from the engine's registry, each with its summary. Swiping left runs through clock, npcs, language, reactions to help; swiping right comes back to memory.
  3. Tapping memory offers every NPC in the world, though the player stands on the village road.
  4. Typing mi narrows to Mícheál Connolly; tapping inserts the full name with fadas.
  5. Sending answers locally: [DEBUG MEMORY: Mícheál Connolly], no Endpoint call.
  6. /debug schedule roisin, typed by hand without fadas, resolves Róisín Connolly in the engine.
The test then checks the Commands button still lists only the advertised four.
