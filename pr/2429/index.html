Each NPC remembers the name the player gave it

A scripted session on the production engine path: the limerick-mobile-ffi session API the iPhone app calls, on the canonical Rundale world, with a scripted Endpoint host answering each call. Each row is one player line, sent with an @tag to that NPC. The cells show the thisMoment.theStranger field of the dialogue Endpoint input sent for that line. This is engine output. It is not app UI and not a physical-iPhone run.

Before: main at 9660d78 (the same engine tree as the #2427 branch head a26f643 it was run from). After: this PR. Highlighted cells differ.

Before, both NPCs were told "Se". The name pattern dropped accented letters, and every NPC that knew any name was given the one global name. After, Peig knows Seán and Mícheál knows Tomás. "Call me Séamus" changes only Peig's name, and "I'm Irish" changes nothing. A name given in a line is known from the next line on, as before. Save and restore of these names, and the loading of a real format 4 save, are covered by tests (see the PR).
