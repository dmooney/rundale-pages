PR 2331: /new starts a fresh game

dmooney/Rundale#2331

What this is: a recording of the testNewGameStartsFreshOfflineAndResumesAfterRelaunch UI test. It runs the real Rundale app on the Limerick engine in the iOS simulator, offline. It is not physical-iPhone validation.

  1. /wait 60 runs in the opening scene.
  2. /new, picked from completion, replaces it with a fresh opening scene.
  3. /wait 7 runs; the app is relaunched and resumes that new game.
  4. /NEW-GAME (the alias, in upper case) starts another fresh game.
  5. /help lists /new: Start a new game.

The holds at the start and end are frozen frames added so each state can be read.
