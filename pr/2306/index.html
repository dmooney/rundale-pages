Remove retry checkpoint

PR #2306, part of #2287. This deletes UI-test-only code; nothing a player sees or does changes, so there is nothing to record on screen.

What goes

RundalePresentationModel.uiTestCheckpoint was set to "Retry accepted and persisted" in UI-test launches only, after a Retry was accepted, and exposed as the accessibility value of the fixture's Next button (fixture.step). The only test that read it was deleted in #2303; no test, script or document refers to it now (grep -rn uiTestCheckpoint mobile docs finds nothing). Retry itself is unchanged.

  • verify.py --fast (SwiftLint, SwiftFormat, the three Swift packages) passes on Linux.
  • This PR's hosted smoke gate builds the app and runs the unit and core-loop UI tests on the simulator.
