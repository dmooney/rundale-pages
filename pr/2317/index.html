The new tests fail when the code is broken

Each change below was made by hand, the test was run, and the source was then restored.

  • Sending the call id unchanged as X-Attempt-Id, instead of with "#" made ".", fails testATurnDecides…. The recorded attempt ids were attempt-1#1 and attempt-1#2, where attempt-1.1 and attempt-1.2 were expected.
  • Dropping the server-side cancel on Stop fails testStopCancels…. The last request was the stream POST, where a DELETE carrying attempt id attempt-1.2 was expected.
