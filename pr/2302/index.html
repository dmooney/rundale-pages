An intent call with no answer fails visibly, and Retry recovers

PR 2302 (issue 1825) at commit 2b3d4b0fc. iOS Simulator (iPhone 17 Pro) with the mock Endpoint; not a physical iPhone (waived) and not live inference.

The player types ask Mícheál busy once. The mock Endpoint rate-limits the intent call on the first attempt only. Before this change the game guessed the line was speech and Mícheál answered; now the request fails with the mod's busy line and a Retry button, and no one answers a line the game could not read. After Retry, the intent call succeeds and Mícheál answers.

Driven by an uncommitted XCUITest driver with demo holds (TEST_RUNNER_RUNDALE_DEMO_HOLD=3); the committed change includes only the mock Endpoint's busy once trigger. The rule itself is checked for every no-answer reason in limerick-core/tests/turn_lifecycle.rs, and the app's error mapping in EndpointFailureClassificationTests.
