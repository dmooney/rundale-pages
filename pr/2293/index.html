The recording is the whole test (about 60 s): four turns, each sent and then stopped with the Stop button at a longer delay.

Method

A dialogue reply streams for under a second and a Stop tap takes about a second to land, so the test sends the same line four times and taps Stop at stepped delays (0.2, 0.35, 0.5, 0.65 s plus tap latency). The app's cancel path sends DELETE on the Endpoint route for the active stream. An attempt counts only if the app offers Retry for the stopped request, the readable transcript trace shows that turn's accepted command and no failed row, and no dialogue row committed; the test fails if no attempt counts. Whether the server recorded a cancellation is checked separately, below.
